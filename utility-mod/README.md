# ClearSight Utilities

Client-side Fabric utility mod for Minecraft Java 1.21.11.

## Features

- Hide the first-person fire overlay while burning.
- Disable camera tilt when taking damage.
- Optionally hide portal distortion and the vignette.
- Resize the held Totem of Undying and its activation animation.
- Settings menu on **H**; each change is saved to `.minecraft/config/clearsight-utilities.properties`.

## Build

Requires Java 21 and Gradle. Run `gradle build` in this directory. The release JAR is under `build/libs/`.

Only install it in a Minecraft Java 1.21.11 Fabric profile with Fabric API.
